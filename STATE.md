# Project Gauntlet - State

Static recompilation of **Gauntlet: Dark Legacy (Xbox, USA)** to PC.

## Inputs (verified 2026-11-15)
- `Gauntlet - Dark Legacy (USA).xiso.iso` (952,434,688 bytes, trimmed XISO, partition at 0) in repo root, git-ignored.
- Extracted with `python -I tools/extract_xiso.py <iso> game` -> `game/` (2480 files, 909 MB, git-ignored).
  Assets keep PS2 names (`*.PS2`): the Xbox version is a PS2 port.
- `game/Default.xbe` (1,253,376 bytes), from `tools/xbe_info.py`:
  - retail XBE, base 0x10000, image size 0xBECDC0, entry 0x000B389B, kernel thunk 0x00114140, TLS 0x00115514, stack 0x40000.
  - PE origin `C:\proj\gauntlet\Code\Release\shell3D.exe`, PE timestamp 0x3C9BB794 (2002-03-22).
  - XDK 4242 for all libs: XAPILIB D3D8 D3DX8 XGRAPHC DSOUND XBOXKRNL WMVDEC LIBCPMT LIBCMT.
  - Sections: .text 0x11000 (0xAF9FC), D3D, D3DX, XGRPH, DSOUND, WMVDEC, XPP, .rdata 0x114140, .data 0x116320 (vsize 0xADC3FC, BSS heavy), .XID, .XPP&Dat, DOLBY, $$XTIMAGE, $$XSIMAGE.
  - 100 kernel imports.
- `game/shell3D.pdb`: VC6 "program database 2.00" (JG). Read with `tools/pdb2.py` (info | publics | stream).
  - 9207 publics (S_PUB32_ST), 6134 PROCREF, 7608 UDT, plus module info and types.
  - NOT the same build as Default.xbe: its PE section table (in the PDB) has .text 0xD3A7A and D3D 0x17130 vs the XBE's 0xAF9FC / 0xFDE0 (probably debug XDK libs), and PDB signature 0x3C9BD347 is ~2 h after the XBE PE timestamp.
  - Use names, types and module lists as reference; addresses must be matched to the XBE (function signatures, strings, call graph).

## Done
- 2026-11-15: approach decided, see `docs/design.md`: x86 -> C static recomp, 64-bit host, NV2A push-buffer translation, DSOUND HLE.
- `tools/pdb2.py procs|modules` (per-module S_GPROC32_ST/S_LPROC32_ST with sizes, 7405 procs, 503 modules).
- `tools/match_pdb.py <xbe> <pdb> <out.tsv>` maps PDB procs to XBE .text: 1554 exact/moved of 4656 seg-1 procs (40 s). main = 0x11C10, mainXapiStartup = 0xB382C, mainCRTStartup = entry 0xB389B.
- `tools/xbedis.py <xbe> <va> [n]` capstone disassembly (pip capstone 5.0.7).

- 2026-11-15: lifter `recomp/lift.py` (Python + capstone -> C). `sh tools/relift.sh` = lift + compile (clang-cl, ~1 min) + oracle DLL.
  - Discovery: strong seeds (entry, PDB exact/moved from `assets/pdb_match.tsv`, call targets), weak seeds (data pointers,
    push/mov imm32 into code) dropped if their body hits junk opcodes. 4063 functions, 348k insns (some tail duplication),
    .text coverage 96.0%; 246 jump tables (bounded by cmp on the index reg, or unbounded state-machine tables near the jmp).
  - Output `out/lifted/`: f_NNN.c, funcs.h, functable.c, functions.tsv (va, insns, calls, fs, indirect, leaf, PDB name),
    lift_report.txt (unimplemented mnemonics, coverage, largest gaps). 45 unimplemented sites (cvtps2pi, pshufw, fnsave/frstor).
  - Model: regs + flags are C locals (clang drops dead flag math), synced to X86Context around calls; guest stack is real,
    `ret` = C return; x87 = ctx.st[8] doubles + top; MMX/SSE helpers in recomp/include/x86simd.h.
  - `assets/pdb_match.tsv` is git-ignored (disc-derived); regenerate with tools/match_pdb.py. It was pushed once in 8f8fc8c.
- Differential oracle: `out/oracle.dll` (runtime/oracle/oracle.c) vs unicorn on original bytes:
  `python -I tools/oracle_test.py [--trials N] [--only VA,..] [-v]` (~6 min for all leaves). Leaf functions: 875 pass,
  3 known fails (C6E90/D8FA6 `fyl2x` negative input: unicorn/QEMU does not pop; C9290 = rdtsc), 108 skipped (inputs fault).
  Bugs it found and fixed: fxch with implicit st(0) operand, fsubp/fdivp one-operand forms, rep movsd overlap, 8/16-bit shift UB.

- 2026-11-15: runtime `out/gauntlet.exe` (runtime/src: main.c memory.c loader.c sched.c kernel.c fs.c, kexports.h
  generated by tools/gen_kexports.py from runtime/kernel/xboxkrnl.exe.def, CC0 from nxdk). Build: `sh tools/relift.sh`
  (lift + objects + oracle + runtime) or `tools\build_runtime.bat` alone. Run from repo root: `./out/gauntlet.exe`.
  - Memory: 64 MB RAM section mapped at guest 0 and 0x80000000; heap 0xC00000-0x3F00000 (first-fit); kernel area
    0x8F000000; kernel sentinels 0x8FF00000+ord*4; 0xFD000000-0xFFFFFFFF dummy RAM (NV2A/APU MMIO not emulated).
  - Threads: fibers, cooperative; DPC host thread; timers polled by the scheduler. Per-thread KPCR (fs_base).
  - FS: D: = game/, \Device\Harddisk0\PartitionN = out/hdd/pN, partition0 = out/hdd/p0.bin (1 MB zeros).
    DVD security MODE SENSE page 0x3E answered as authenticated. Title ID 4D57000E. T:/U:/Z: mount OK.
  - Env: GT_KLOG=1 (log kernel calls), GT_WATCHDOG=<s> (host stack samples; pipe through tools/symbolize.py).
  - Missed indirect targets go to out/missed_targets.txt; relift.sh merges them into recomp/seeds_extra.txt.
    Data pointers inside function-pointer tables are now seeds (CRT initializers): 4773 functions.
  - (old) boot status: hung in D3D device creation polling NV2A registers; fixed 2026-11-16 (below).

- 2026-11-16: boot passes D3D device creation, XPP input init, and starts loading assets.
  - `runtime/src/nv2a.c`: the lifter emits MMIO-checked RD/WR*X for the IO_RANGES sections (D3D, DSOUND) in lift.py.
    The GPU is always idle: W1C interrupt registers, derived PMC_INTR, PFIFO idle bits, PFB flush. On a DMA_PUT
    write the pusher runs GET..PUT (jump/call/return, inc/non-inc methods) and executes Kelvin semaphore releases
    (0x1A4 SET_CONTEXT_DMA_SEMAPHORE, 0x1D6C, 0x1D70) through the RAMHT scan and DMA object (fences at 0xC91000).
    `GT_NVLOG=1` logs first touch per register, `GT_PBLOG=1` logs every method.
  - Kernel: KINTERRUPT objects; `kernel_raise_irq` runs the ISR on the DPC thread; 60 Hz vblank (GPU IRQ 3).
    The KeTickCount host ticker runs at 1 ms. `sched_maybe_yield()` (1 ms slices) at polling points: HLE calls,
    MMIO reads, kernel calls.
  - HLE overrides: `recomp/hle.txt` (VA name); the lifter emits `x86_hle(c, va)` stubs, implemented in
    runtime/src/hle.c. Current overrides: XInput* / XGetDevices / XGetDeviceChanges / XInitDevices (one pad on port 0
    from host XInput) and GetTickCount (B1B72).
  - fs: drive-letter names (`D:\x`) map to `\??\D:`.
  - Lifter fixes: strong seeds stay strong when first reached as weak immediates; section reads are zero-padded to vsize.
  - APU stub: 0xFE820010 = 48 kHz counter.
  - BOOT STATUS: models and textures load (sony/objects.ps2, textures.ps2). DSOUND init polls the AC97 (FEC00130)
    and then crashes on a DEADBEEF object (f_000D50F5, called from f_0002E5C0). Register-level APU emulation is a dead end.

- 2026-11-16: DSOUND HLE at the C-API level (`runtime/src/dsound.c`, entries in `recomp/hle.txt`).
  - 18 wrappers matched to PDB section 5 by order + stdcall arg bytes (IDirectSound_* adjust -8, IDirectSoundBuffer_* -0x1C).
    The lifter turns every other DSOUND function into a fatal HLE stub, except CRT initializers DA2BB/DA2C6 (DSOUND_LIFT).
  - Stream objects (WMV player) have a guest vtable of sentinels HSENTINEL_BASE 0x8FF80000+slot*4, dispatched in
    x86_call_indirect: AddRef/Release/GetInfo/Process/Discontinuity/Flush. Packets complete at once into a host FIFO.
  - Host mixer thread (waveOut 48 kHz) owns play cursors; PCM 8/16 + Xbox ADPCM (tag 0x69, 36-byte blocks, 64 frames).
    Play flags: LOOPING 1, FROMSTART 2. Env: GT_NOAUDIO=1, GT_WAVDUMP=<raw s16 file>, GT_DSLOG=1.
  - Lifter: cvtps2pi/cvttps2pi/cvtpi2ps/pshufw. nv2a: PVIDEO_BUFFER (0x8700) reads 0 (overlay idle).
  - BOOT STATUS: midway/opening/title2 movies play with audio (WAVDUMP verified), attract mode loads levels, select
    screen banks (*.vbk), SFX buffers play (ADPCM mono). No crash in 150 s. Nothing is displayed yet (no renderer).
    Remaining unimplemented lift sites: segment mov 9, enter 4, fnsave/frstor. `in` port 0x80C0 polled (logged, returns 0).

- 2026-11-15: D3D11 renderer (`runtime/src/gpu_d3d11.c`, interface `kelvin.h`). Movies, title, attract 3D levels render.
  - nv2a.c stores every Kelvin method in `g_kreg[method>>2]`, fetches vertices (DRAW_ARRAYS = separate primitives,
    ARRAY_ELEMENT16/32), builds index lists, calls gpu_draw / gpu_clear / gpu_flip. INLINE_ARRAY not done (logged).
  - Frame flip: XDK Swap writes the finished surface offset to 1D8C (scratch) then FLIP_INCREMENT_WRITE (0x12C);
    PCRTC_START is always 0 here, so it is not used.
  - Game state seen: 640x480 A8R8G8B8 + Z24S8, surfaces 00E20000/00F4C000, zeta 01078000, one VB ring at 011A4000
    (pos f3, diffuse D3DCOLOR, uv0, uv1; stride 32), fixed-function (1E94=4), lighting off, composite matrix only,
    I8 paletted swizzled textures, 1-2 combiner stages (PS2 colors: color OCW scale x2).
  - Combiner OCW bits: 3:0 CD dst, 7:4 AB dst, 11:8 SUM dst, 12 CD dot, 13 AB dot, 14 mux, 15 bias, 17:16 scale,
    18/19 CD/AB blue-to-alpha (XDK PS_COMBINEROUTPUT << 12). Final combiner CW0 A..D, CW1 E,F,G + bit7 sum clamp.
  - Culling is off (CULL_FACE alternates per draw; winding unverified). Fog, lighting, vertex programs, cube maps,
    stage modes other than 2D/pass-through: not done (each logs once).
  - Overlay: PVIDEO buffer 0 at 02E16000, 320x240 YUY2 pitch 640, shown via gpu_vblank (DPC thread) when no 3D flip
    for 250 ms. gpu_* calls are serialized by an SRW lock.
  - Env: GT_SHOT=N (out/shots/fNNNNN.bmp every N flips, ovNNNNN.ppm for overlay), GT_PBFRAME=N (log methods of
    frame N), GT_PSDUMP=1, GT_NODRAW=1, GT_D3DDEBUG=1. ESC or closing the window exits.
  - Speed: 29.4 fps everywhere (game's 30 Hz cap), with draws on.
